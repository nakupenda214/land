# 页面设计说明：表格统一布局与底部导航

## 全局设计（适用于全部页面，桌面优先）
### Layout
- 采用“顶部标题区 + 内容区 + 底部导航条”三段式结构。
- 内容区为可滚动容器；底部导航条 fixed 在视窗底部。
- 内容区底部必须留出 padding-bottom = navHeight + safeSpacing，确保最后一行/汇总行不被遮挡。

### Meta Information
- title：按页面名（首页/项目方汇总表/规划复核表）
- description：描述“数据表查看与复核”
- Open Graph：og:title 与 title 一致；og:type=website

### Global Styles（设计 tokens 建议）
- 页面背景：#F7F8FA
- 主文字：#1F2329；次级文字：#646A73
- 主色（选中态/强调）：#1677FF
- 边框/分割线：#E5E6EB
- 字体：系统默认（优先苹方/Segoe UI）；字号层级 12/14/16/20
- 按钮/可点击：hover 提升对比（背景加深 4% 或下划线）；focus 显示清晰描边

### 统一底部导航条（Bottom Nav）
- 结构：最多 3–5 个导航项（本需求至少包含：首页、项目方汇总表、规划复核表）。
- 单项样式：图标（可选）+ 文案；文案不换行、超出省略。
- 高度：固定高度（建议 56px），上方 1px 分割线。
- 状态：
  - 默认：次级文字色
  - 选中：主色 +（字重或指示条二选一，避免叠加）
  - 禁用：降低不透明度且不可点击
- 交互：
  - 点击当前选中项：不刷新、不滚动到顶（保持稳定）
  - 点击未选中项：立即切换页面；路由变化后更新选中态

### 表格统一布局规则（两张表共用）
- 表头固定：表格纵向滚动时表头保持可见。
- 横向滚动：列多时允许横向滚动；首列是否固定以现有产品为准（本次不新增强制）。
- 空态：无数据时显示统一空态（标题 + 简短说明）。
- 对齐：数值右对齐；文本左对齐；表头与内容保持一致。

## 页面 1：首页/工作台
### Page Structure
- 顶部：页面标题（“工作台”）
- 中部：入口卡片区（两张表入口）
- 底部：统一底部导航条

### Sections & Components
1. 顶部标题栏
   - 左：页面标题
2. 入口卡片区（Grid）
   - 卡片 A：项目方汇总表（说明一句话 + 进入按钮）
   - 卡片 B：规划复核表（说明一句话 + 进入按钮）
3. Bottom Nav
   - “首页”选中态

## 页面 2：项目方汇总表（实测汇总行表）
### Page Structure
- 顶部：标题区（页面名）
- 中部：表格容器（可滚动）
- 底部：汇总行区域（在表格内固定到可视底部） + Bottom Nav（最底层固定）

### Sections & Components
1. 顶部标题栏
   - 标题：项目方汇总表
2. 表格容器（可滚动区域）
   - 固定表头
   - 表格主体（行）
3. 实测汇总行（关键）
   - 固定在“内容区可视底部”，但必须位于 Bottom Nav 之上
   - 与表格列对齐，背景与分割线明显
4. Bottom Nav
   - “项目方汇总表”选中态

### Interaction Notes
- 滚动时：表头固定、汇总行可见；Bottom Nav 常驻。
- 触底时：最后一行仍可完整可见（依赖安全区 padding）。

## 页面 3：规划复核表（section表格）
### Page Structure
- 顶部：标题区
- 中部：section 列表（每个 section 包含标题 + 表格）
- 底部：Bottom Nav

### Sections & Components
1. 顶部标题栏
   - 标题：规划复核表
2. Section 列表（垂直堆叠）
   - Section Header：分区名称/简要说明（保持强可读）
   - Section Table：固定表头 + 行列内容
   - Section 间距与分割线统一
3. Bottom Nav
   - “规划复核表”选中态

### Interaction Notes
- 页面纵向滚动跨 section；Bottom Nav 常驻。
- section 标题需在滚动中保持“归属感”（至少通过明显样式与间距；如需吸顶属于增强项，本次不强制）。
